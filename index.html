FrameForge

Windows-приложение для игровых профилей и измерения frametime: обратимые настройки Skyrim, A/B-бенчмарки и локальная история. Для CS:GO Legacy автоматически находит установленную игру в Steam, создаёт резервную копию конфигурации, собирает профиль FPS и по выбору загружает текстовое меню через игровую консоль. Версия 1.17.0 добавляет отдельную панель поверх окна игры в оконном режиме без рамки; это desktop overlay, а не встроенный интерфейс игры. Версия 1.18.0 умеет по запросу записывать frametime через выбранный PresentMon для указанного процесса на 30–300 секунд и автоматически добавлять CSV в локальную A/B-историю. В 1.18.1 исправлено распознавание `FrameType=Application` без учёта регистра для CPU-presented CSV. Захват требует системного доступа к ETW; прирост FPS не гарантируется. Приложение не обещает фиксированный прирост FPS.
